SETUP NOTES

Connect your boards

  1. Connect each ESP32 to the same Wi-Fi network as this computer.
  2. Find each board’s IP in the Arduino Serial Monitor and add it above.
  3. The firmware must expose /api/test and /api/status.
Device settings, activity, and sensor readings are stored in Firebase Cloud Firestore. Access-control actions are forwarded to the selected ESP32.
